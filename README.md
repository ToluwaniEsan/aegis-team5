# Project AEGIS · Team 5: Payload & Operator Interface

Team 5's subsystem for **Project AEGIS** (Autonomous Expeditionary Ground Support System), the AAMU Senior Problem class project. We own payload delivery, the operator screen, and the operator's command and alert flow.

**Team:** Olasubomi Awodipe, Toluwani Esan, Mercy Akinyemi, Solomon Agyire, Emmanuel Aina, Zizwe Mtonga

This repo starts with documentation only. Code gets added in Sprint 4.

## Getting started

1. Read `docs/design-decisions.md` and `docs/architecture.md`.
2. Pick a Sprint 4 item from `docs/process.md` and open a GitHub Issue for it.
3. Work on a branch named `feature/WI-###-short-name` and open a pull request into `main`.
4. Update the Code, Test and Status columns in `docs/requirements.md` as you finish work.
